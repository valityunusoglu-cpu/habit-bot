# Личный трекер: привычки, задачи, заметки

Telegram-бот с мини-приложением.

**Что умеет**
- **Сегодня** — привычки и задачи на день, листание по дням (можно отметить вчерашнее).
- **Привычки трёх видов:** «каждый день», «N раз в неделю» (например, спортзал 3 раза) и **группа** — раскрывается, внутри отдельные пункты (Намаз → Фаджр, Зухр, Аср, Магриб, Иша).
- **Задачи** с напоминанием: бот пишет в нужное время, в сообщении кнопки «✅ Выполнено» и «⏰ Через час». Невыполненные задачи можно перенести на сегодня одной кнопкой.
- **Напоминания для привычек** (по желанию): бот напомнит, только если привычка ещё не отмечена.
- **Месяц** — таблица всех привычек: ✓ выполнено, ✕ пропущено, цифра — сколько пунктов группы сделано. Итог по каждой привычке, процент за месяц и «идеальные дни».
- **Заметки.**
- **Ибадат** — время намазов для Измита (метод Diyanet), фард и сунна-намазы (шафиитский мазхаб), витр, духа, тахаджуд, Коран; утренние, вечерние и послемолитвенные азкары с арабским текстом, транскрипцией и переводом; тасбих. Бот напоминает о начале времени намаза (кнопка «✅ Помолился»), `/namaz` — время на сегодня.
- **Еда** — дневник питания со счётом калорий и БЖУ, норма для набора веса, план питания на день, свои продукты, учёт веса с графиком.
- **Спорт** — программа на 3 дня в неделю (тренировки A/B) с картинками и техникой, запись подходов и весов, прошлый результат подставляется сам.
- **Ещё → Профиль** — возраст, рост, вес, цель, дни тренировок. Город (Измит, Идлиб, Харим, Фуа) и поправки времени каждого намаза в минутах — тоже там.
- **В самом боте:** `/today` — сводка дня; любой текст боту → кнопки «Задача на сегодня» / «Заметка».

При первом запуске уже созданы: Намаз (5 молитв), «Прочитать книгу», «Спортзал — 3 раза в неделю». Всё меняется во вкладке «Привычки».

## Бесплатный запуск: Render + Neon

- **Render** — бесплатный сервер, на котором работает бот.
- **Neon** — бесплатная база данных. Она нужна, потому что бесплатный Render стирает файлы при каждом перезапуске.

Карта нигде не нужна. Займёт примерно 20 минут.

### Шаг 1. Создай бота
1. Открой в Telegram **@BotFather** → `/newbot`.
2. Придумай имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...` — сохрани его и никому не показывай.

### Шаг 2. Создай базу в Neon
1. Зайди на **neon.com** → Sign up (удобно через Google или GitHub).
2. Создай проект: любое имя, регион — **Europe (Frankfurt)**, он ближе всего.
3. Нажми **Connect** и скопируй строку подключения. Она выглядит так:
   `postgresql://neondb_owner:пароль@ep-....eu-central-1.aws.neon.tech/neondb?sslmode=require`
   Это твой `DATABASE_URL`. Тоже никому не показывай.

### Шаг 3. Загрузи код на GitHub
1. Зарегистрируйся на **github.com**, если ещё нет аккаунта.
2. Нажми **New repository** → любое имя, например `habit-bot` → можно выбрать **Private** → **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи туда **содержимое** папки `habit-bot` (файлы `app.py`, `Dockerfile`, `render.yaml`, папку `webapp` и остальные) → **Commit changes**.

### Шаг 4. Запусти на Render
1. Зайди на **render.com** → Sign up **через GitHub**.
2. **New → Blueprint** → выбери свой репозиторий. Render прочитает файл `render.yaml` и попросит заполнить:
   - `BOT_TOKEN` — токен из шага 1
   - `DATABASE_URL` — строка из шага 2
   - `OWNER_ID` — пока оставь пустым
3. Нажми **Deploy** и подожди несколько минут. В логах должно появиться «Веб-сервер запущен» и «База: PostgreSQL».

> Если пункта Blueprint нет: **New → Web Service** → выбери репозиторий → Language: **Docker** → Instance type: **Free**. Переменные `BOT_TOKEN`, `DATABASE_URL`, `TIMEZONE=Asia/Damascus` добавь в разделе **Environment**.

Адрес приложения (`https://....onrender.com`) Render подставит в бота сам — указывать его не нужно.

### Шаг 5. Закрой бота для чужих
1. Напиши боту `/start`, потом `/id` — он пришлёт твой Telegram ID.
2. На Render: сервис → **Environment** → `OWNER_ID` = это число → **Save**. Сервис перезапустится, и бот будет отвечать только тебе.

Готово: нажми в боте **«Открыть трекер»** или кнопку **«Трекер»** слева от поля ввода.

### Как бот не «засыпает»
Бесплатный Render усыпляет сервер через 15 минут без запросов. Поэтому бот сам обращается к своему адресу каждые 10 минут — и не засыпает.
Для надёжности можно добавить внешний «будильник»: зарегистрируйся на **cron-job.org** и создай задание, которое каждые 10 минут открывает `https://твой-адрес.onrender.com/health`.

Если сервер всё же уснёт (например, после перезапуска на стороне Render), первое открытие приложения займёт около минуты, а напоминания за время сна придут с опозданием.

### Обновление кода
Загрузи изменённые файлы в тот же репозиторий на GitHub — Render сам пересоберёт и перезапустит бота. Данные в Neon при этом сохраняются.

## Другие варианты запуска

**Свой сервер или Oracle Cloud Free:**
```bash
git clone <твой-репозиторий> habit-bot && cd habit-bot
python3 -m venv venv && . venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заполни BOT_TOKEN, WEBAPP_URL, OWNER_ID
python app.py
```
Без `DATABASE_URL` данные хранятся в файле `data/habits.db`. Приложение слушает порт `8080` (переменная `PORT`). Telegram открывает мини-приложения только по **https**, поэтому нужен домен с HTTPS — например, через Caddy (`reverse_proxy localhost:8080`).

**Проверка интерфейса в браузере без Telegram:**
```bash
DEV_MODE=1 python app.py
```
и открой `http://localhost:8080`. **На сервере `DEV_MODE` не включай** — он отключает проверку, что запрос пришёл из Telegram.

## Как это устроено
- `app.py` — всё в одном процессе: веб-сервер (мини-приложение + API), бот (aiogram) и напоминания.
- `webapp/` — интерфейс (HTML/CSS/JS, без сборки).
- База — PostgreSQL (если задан `DATABASE_URL`) или файл SQLite.
- Напоминания: бот вычисляет время ближайшего напоминания и обращается к базе только тогда, а не постоянно. Так бесплатная база Neon может «спать» и не тратит лимит.
- Каждый запрос из мини-приложения проверяется по подписи Telegram, поэтому подделать доступ нельзя.
- Если сервер был выключен, напоминания о привычках старше 3 часов не присылаются, чтобы не прилетела пачка старых.
